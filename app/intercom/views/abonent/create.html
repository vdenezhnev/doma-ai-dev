Этаж
Поле «Этаж» заполняется для получения доступа к функции умный лифт.
Данное поле отвечает за отправку пользователя с первого этажа или парковки, на указанный этаж.

Нижний этаж
Поле «Нижний этаж» так же заполняется для получения доступа к функции умный лифт.
Данное поле отвечает за возможность пользователя спускаться со своего этажа на диапазон выбранных этажей (от 0 (первый этаж) до -5 (-1/-2/-3/-4/-5))

Помещение
Поле «Помещение» является номером квартиры пользователя

ID выданной карты или метки
Поле «ID выданной карты или метки» отвечает за дополнительный доступ к замкам с помощью карты или метки, а также передает ID по интерфейсу Wiegand

Администратор
Флаг «Администратор» - отвечает за доступ к конфигурации контроллера
